# @emsenn/organizing-a-knowledge-vault

The organizing downstream specialization for this repo's `content/` trees.

This package owns the filepath-vault boundary: resolving topic proof paths, browsing
generated frontiers, reading markdown resources through relating's codecs, preparing
frontmatter documents, and admitting bounded regions as knowing memory/research.

`@emsenn/knowing` keeps the epistemic core: proof search, concept formation, memory,
and research carriers. This package only specializes those capabilities to the
concrete filepath-tree law used by the 561 Group content vaults.

```sh
echo mark/utterance | organize-knowledge-vault locate --path content
echo mark | organize-knowledge-vault browse --path content
echo "" | organize-knowledge-vault settle-memory --path content --limit 50
```
