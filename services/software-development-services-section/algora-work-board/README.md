This root owns no aggregate runtime. It is the verified circuit board that composes thirteen sovereign dies under `services/`:

1. board conduction;
2. opportunity observation;
3. work-risk assay;
4. deterministic qualification;
5. resource allocation;
6. repository-material observation;
7. patch synthesis through the customer-owned inference market;
8. static verification;
9. remote sandbox execution;
10. differential adjudication;
11. authorized attempt publication;
12. witness-journal RDF witnessing; and
13. rectification assay.

Every die has one RMN law, one black-box circuit interface, settlement-owned Agent Card signing material, and its own live ERC-4337 account. The board implementation and sovereign placement are in `content/circuits/implementation.rml` and `content/circuits/assembly.rml`.

The only conductor executable is:

```sh
services/algora-work-board-conductor/scripts/run-loop.mjs --live \
  --observed-at 2026-07-21T00:00:00Z --dry
```

Wet execution admits only the explicitly selected remote GitHub Actions carrier. There is no local executor, JSON-file input path, direct provider selection, implicit escalation, or fallback.
