# Software Development Services Section

This section groups the Union's agentic software-development capability under
`rsc-quiescent` — the actors that observe, assay, allocate, synthesize,
execute, adjudicate, publish, witness, and rectify software work as its own
sovereign line of business, as distinct from the persistent machines or the
brokerage/market sections that sit alongside it under `services/`.

## What's here

- `services/` — one child package per seated software-development actor.

The first (and so far only) actor seated here is
[`algora-work-board`](services/algora-work-board/), the verified circuit
board that composes the thirteen sovereign dies of the Algora software-work
pipeline: board conduction, opportunity observation, work-risk assay,
deterministic qualification, resource allocation, repository-material
observation, patch synthesis through the customer-owned inference market,
static verification, remote sandbox execution, differential adjudication,
authorized attempt publication, witness-journal RDF witnessing, and rectification assay.
It moved here from `red-cup-engineering` as part of the settlement chain
cutover; see its own README for the die-by-die detail.
